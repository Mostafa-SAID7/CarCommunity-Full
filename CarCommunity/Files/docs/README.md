# AutoSphere Documentation

Welcome to the **AutoSphere** developer documentation suite.  
This repository outlines the full architecture, implementation, and roadmap for the AutoSphere car community platform — a full-stack solution built with **ASP.NET Core Web API** and **Angular 17+**.

**Stack:**  
- Backend: ASP.NET Core 8 Web API, EF Core, FluentValidation  
- Frontend: Angular 17+, TailwindCSS, RxJS, NgRx/Signals  
- Database: SQL Server 2022  
- Deployment: Azure App Service + Static Web Apps
