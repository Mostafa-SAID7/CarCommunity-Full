# AutoSphere Overview

## 🎯 Vision
Create the world’s most interactive **car community platform**, connecting car enthusiasts globally through technology.

## 🧩 Mission
Provide a unified hub for car owners to:
- Showcase their vehicles and modifications  
- Engage in live community discussions  
- Attend and manage events  
- Build reputation through engagement and contributions  

## 🧠 Guiding Principles
- **Clean Architecture** for scalability and maintainability.  
- **Separation of concerns** between backend (API) and frontend (Angular).  
- **API-first design** with consistent REST contracts.  
- **Performance-driven UI/UX** optimized for real-world users.  

## 🧰 Technology Stack
| Layer | Technology |
|-------|-------------|
| Backend | ASP.NET Core 8 Web API |
| Frontend | Angular 17+, TailwindCSS |
| Database | SQL Server 2022 |
| Authentication | JWT + ASP.NET Core Identity |
| Real-Time | SignalR + Azure SignalR Service |
| Deployment | Azure App Service / Static Web Apps |
| CI/CD | GitHub Actions |
| AI | Azure Cognitive Services / Custom Vision |
