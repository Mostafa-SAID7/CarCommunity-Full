## 🧩 Technology Stack

The Rev Assist frontend is engineered for **performance, maintainability, and scalability**, leveraging a modern development toolchain:

| Layer | Technology |
|-------|-------------|
| Frontend Framework | **React + TypeScript** |
| Build Tool | **Vite** |
| UI Framework | **shadcn/ui** |
| Styling | **Tailwind CSS** |
| Backend | **ASP.NET Core Web API** *(via integrated service layer)* |
| Data Access | **Entity Framework Core + SQL Server** |
| Deployment | **Lovable Platform**, CI/CD with **GitHub Actions** |
| Hosting | **Azure App Service** |

## ⚙️ How to Edit the Project

You have multiple options to contribute or iterate on this project:

### 🧠 Option 1 — Use Lovable (Recommended)
Lovable offers seamless AI-assisted development with automatic commits.

1. Visit the project page → [Lovable Project](https://lovable.dev/projects/8b8e7d4d-23c1-4792-892a-cc372547e226)  
2. Prompt Lovable with your desired changes or feature requests.  
3. Watch updates get committed to your repository automatically.

---

### 💻 Option 2 — Use Your Preferred IDE (Local Development)

You can clone and develop locally using **VS Code**, **WebStorm**, or any IDE of choice.

#### 🪜 Setup Steps

```bash
# 1️⃣ Clone the repository using your project’s Git URL
git clone <YOUR_GIT_URL>

# 2️⃣ Navigate to your project directory
cd <YOUR_PROJECT_NAME>

# 3️⃣ Install dependencies
npm install

# 4️⃣ Start the development server with auto-reload & preview
npm run dev
```

> 💡 **Tip:** Ensure that [Node.js](https://nodejs.org) (v18 or newer) and [npm](https://www.npmjs.com/) are installed.  
> For smooth version management, install Node via [nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

---

### 🧾 Option 3 — Edit Files Directly in GitHub

1. Navigate to the target file in the repository.  
2. Click the **Edit (🖉)** icon at the top-right corner.  
3. Apply changes → add a commit message → select **Commit changes**.  

---

### 🧰 Option 4 — Use GitHub Codespaces

Run your entire dev environment in the cloud with no local setup.

1. Go to your repository’s main page.  
2. Click **Code → Codespaces → New codespace**.  
3. Start coding instantly within a preconfigured dev container.  

> ✅ All dependencies are preinstalled — no setup hassles.
